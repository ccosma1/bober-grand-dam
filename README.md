# Bober Grand Dam

Fan game by a holder. Unofficial — not the project team.

Race the bank. Boost the dam. First to the crest wins.

Five local circuits: Dam Loop, Frost Ridge, Crown Clover, Oasis Leap, and Sky Loop 360. Three laps. You and three racers. Boxes on the road. FIRE throws what you hold: BOOST, Stick Trap, Pinecone Barrage, Dam Surge, Lodge Magnet, Bark Buckler, Meteor Chip, and Resin Slick.

No wallet.

Live: https://ccosma1.github.io/bober-grand-dam/
